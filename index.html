Key presets · primary drones (Scott Dixon chart)

A key button replaces whatever is sounding with that key's primary drone pairs, each voiced as root plus a perfect fifth above at the selected octave. Press the same key again to stop it. Wedge taps still add or remove single tones. Centre hub or Escape silences everything.
