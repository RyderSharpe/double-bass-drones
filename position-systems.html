Two Position Systems

Simandl and Rabbath compared along the G string, one semitone per row.

Simandl

Zimmermann / Drew International ed., Applebaum, Essential Elements, String Explorer

Rabbath

Vance / Green / Ellison / Robinson / Proto

Simandl

Each position covers three semitones and starts one semitone above the one before: Half, 1st, 2nd, 2½, 3rd, 3½, 4th, 5th, 5½, 6th, 6½, 7th. Neighbouring positions sit in different columns so they can overlap.

Rabbath

Six longer positions. Each one ends on the pitch where the next begins, and those shared pitches fall on harmonic nodes: C, D, G, D, G.

Generic names

First, Tuning, Block and Thumb are neutral names for the broad regions of the fingerboard that both systems divide up in their own way.
